# מישור הנוף – אפליקציית בית הספר

אפליקציית ווב מתקדמת (PWA) בעברית, מותאמת לנייד, שאפשר להתקין במסך הבית. עובדת גם בלי אינטרנט.

## הפעלה
```bash
cd mishur-hanof && python3 -m http.server 8080
# לפתוח http://localhost:8080
```
בכניסה בוחרים תפקיד: **תלמיד/ה · הורה · מורה · הנהלה**. לכל תפקיד יש מסכים, ניווט ופעולות משלו.

## מה יש בפנים
| תחום | יכולות |
|---|---|
| לימודים | מערכת שעות שבועית עם השיעור הנוכחי בזמן אמת, שינויים במערכת, הפסקות · משימות ושיעורי בית עם מעקב התקדמות · ציונים עם ממוצע משוקלל ומחשבון "מה אם" · נוכחות · משובים מהמורים |
| לוח | לוח חודשי של מבחנים, טיולים, אסיפות וחופשות + ייצוא ליומן (ICS) |
| תקשורת | הודעות בית הספר לפי קטגוריה וקהל יעד, הצמדה ושיתוף · צ'אט ישיר עם הצוות · מרכז התראות וחיפוש גלובלי |
| הורים | חתימה דיגיטלית על אישורים ותשלום · דיווח היעדרות למחנכת · מעבר בין כמה ילדים |
| מורים | רישום נוכחות לכיתה, פרסום משימות, הזנת ציונים, מבחנים ואירועים, שינויי מערכת, משוב לתלמיד, צפייה בדיווחי הורים |
| הנהלה | לוח בקרה, פרסום הודעות, סקרים, טפסים לחתימה, פניות "אוזן קשבת" |
| רווחה וביטחון | "אוזן קשבת" – פנייה ליועצת (גם אנונימית) · מספרי חירום בלחיצה · נהלי אזעקה/שריפה/רעידת אדמה |
| קהילה ושירותים | חוגים והרשמה · סקרים · אבדות ומציאות · הסעות · תפריט צהריים · הספרייה שלי · ספר טלפונים · אודות ושעות צלצול |
| נגישות | מצב כהה/בהיר, טקסט מוגדל, תמיכה ב-reduced motion, ממשק RTL מלא |

## מבנה
- `index.html` – מעטפת · `styles.css` – עיצוב · `app.js` – לוגיקה, מסכים וניתוב
- `data.js` – נתוני הדגמה (התאריכים יחסיים להיום). בגרסת ייצור מחליפים בשרת/API.
- `logo.png` – סמל בית הספר · `sw.js`, `manifest.json`, `icon-*.png` – התקנה ועבודה בלי רשת

> גרסת הדגמה: הנתונים נשמרים ב-localStorage במכשיר. כל שינוי עובר דרך `save()` ב-`app.js`, כך שאפשר לחבר שרת אמיתי בנקודה אחת.
